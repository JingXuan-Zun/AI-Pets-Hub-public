# 在手机 QQ 上跟角色聊天

你给一个 QQ 小号发私信，桌宠里**当前的角色**来回复，就像在聊天窗口里打字一样（同一份记忆、同样能帮你在电脑上做事）。她要做需要确认的事时，会在 QQ 里问你，回复“好”或“不要”就行。支持文字、表情、图片和语音（双向）。

电脑和桌宠需要开着。

## 先说风险

- 用 NapCat、LLBot、SnowLuma 这类工具登录 QQ，不是腾讯官方允许的方式，**账号有被冻结的风险**：请用**小号**，不要用主号。
- 消息会经过腾讯的服务器；聊得越露骨，小号越容易出问题。
- 只有你在设置里填的那个 QQ 号发来的私信才会被回复，别人发的一概不理（角色能操作你的电脑，这一条很重要）。

## 用哪个 QQ 工具

桌宠走通用的 **OneBot v11 正向 WebSocket**，下面这些都能接，功能一样：

- **NapCat（推荐）**：https://github.com/NapNeko/NapCatQQ/releases
- **LLBot（原 LLOneBot）** 等其他 OneBot v11 工具。
- **SnowLuma**：2026 年 11 月收到腾讯律师函后停止公开发布，不会再更新。已经装好的可以先接着用（桌宠会帮它自动启动、自动读 Token），新装请用 NapCat。

## 一、准备 NapCat（这几步要你自己来）

1. 准备一个 QQ 小号，并且**用你的主号加小号为好友**。装好电脑版 QQ。
2. 下载 NapCat 的 Windows 一键包（名字带 Shell、OneKey 的 zip），解压到一个文件夹。
3. 运行里面的启动脚本：它会单独开一个 QQ，用**小号**扫码登录。窗口里会打印 WebUI 地址和登录 Token。
4. 打开 WebUI（一般是 `http://127.0.0.1:6099/webui`），在“网络配置”里新建 **WebSocket 服务器**：
   - 地址：`127.0.0.1`（不要填 0.0.0.0，免得局域网里别人也能连）
   - 端口：`3001`
   - Token：设一个，记下来
   - 启用、保存。

> 其他 OneBot v11 工具也一样：开启正向 WebSocket（也叫 “WebSocket 服务端” / “WS Server”）就能接。

## 二、在桌宠里连接

设置 → 扩展 → **QQ 连接**：

1. **用哪个 QQ 工具**：选 NapCat（或你用的那个）。
2. **你的 QQ 号**：填你的主号（就是你用来发私信的那个号）。
3. **OneBot 正向 WebSocket 地址**：`ws://127.0.0.1:3001`，端口和工具里的一样。
4. **Access Token**：和工具里设的一样；没设就留空。
5. 点 **测试连接**：成功会显示小号的号码。
6. 打开 **开启 QQ 连接**。

NapCat 要你自己启动；关掉它的窗口连接就断了，重新打开后桌宠会自动重连。

## 三、用起来

- 用主号给小号发私信，比如“在吗”“帮我看看明天天气”。
- 想换角色、换模式，就跟平时一样说（比如“切换到某某”）。在群聊模式下，每个角色的回复都会带上名字一起发过来。
- 角色问“需要你确认：……”时，回复“好”就去做，回复“不要”就取消。
- 你十分钟没在 QQ 上说话，桌面上的后续回复就不再转发到 QQ。
