# 在手机 QQ 上跟角色聊天

你给一个 QQ 小号发私信，桌宠里**当前的角色**来回复，就像在聊天窗口里打字一样（同一份记忆、同样能帮你在电脑上做事）。她要做需要确认的事时，会在 QQ 里问你，回复“好”或“不要”就行。

电脑和桌宠需要开着。

## 先说风险

- 用 SnowLuma、NapCat 这类工具登录 QQ，不是腾讯官方允许的方式，**账号有被冻结的风险**：请用**小号**，不要用主号。
- 消息会经过腾讯的服务器；聊得越露骨，小号越容易出问题。
- 只有你在设置里填的那个 QQ 号发来的私信才会被回复，别人发的一概不理（角色能操作你的电脑，这一条很重要）。

## 一、准备 SnowLuma（这几步要你自己来）

1. 准备一个 QQ 小号，并且**用你的主号加小号为好友**。
2. 下载并安装 SnowLuma，用小号扫码登录。
3. 在 SnowLuma 的网络 / OneBot 设置里，开启 **正向 WebSocket**（有的地方叫 “WebSocket 服务端” 或 “WS Server”）：
   - 地址：`127.0.0.1`
   - 端口：记下来（比如 `3001`）
   - Access Token：可以不设；设了的话记下来。
4. 保存，确认 SnowLuma 显示已经在运行。

> 用 NapCat、LLOneBot 之类的其他 OneBot v11 工具也一样：开启正向 WebSocket 就能接。

## 二、在桌宠里连接

设置 → 扩展 → **QQ 连接**：

1. **你的 QQ 号**：填你的主号（就是你用来发私信的那个号）。
2. **OneBot 正向 WebSocket 地址**：`ws://127.0.0.1:端口`，端口和 SnowLuma 里的一样。
3. **Access Token**：SnowLuma 里设了就填一样的，没设就留空。
4. 点 **测试连接**：成功会显示小号的昵称和号码。
5. 打开 **开启 QQ 连接**。

## 三、用起来

- 用主号给小号发私信，比如“在吗”“帮我看看明天天气”。
- 想换角色、换模式，就跟平时一样说（比如“切换到某某”）。在群聊模式下，每个角色的回复都会带上名字一起发过来。
- 角色问“需要你确认：……”时，回复“好”就去做，回复“不要”就取消。
- 你十分钟没在 QQ 上说话，桌面上的后续回复就不再转发到 QQ。

## 还没做的

- 用角色自己的声音发 QQ 语音（下一步）。
- 在 QQ 里发图片给角色看。
