# 关于 AI Pets Hub：能做什么、做不到什么（草稿 v1，2026-11-06）

用途：
1. 新手包里小玲的知识库：用户问“你能做什么”“安全吗”“要花钱吗”时，她按这份回答；这里没写的，就说不知道，不编。
2. 公开说明：整理后放进 README（中 / 英）。

写法原则：只写实测过的；做不到的直接写出来；数字注明测试日期。

---

## 一句话

一个住在你桌面上、有自己性格和记忆的角色。你跟她说一件事，她会在电脑上帮你做完，改东西之前先跟你商量，做完告诉你结果。

## 她能做的事

| 类别 | 例子 |
|---|---|
| 聊天和陪伴 | 按自己的性格聊天；会主动提议“要不要记住这件事”，你同意了才记；可以用语音跟她说话 |
| 操作电脑 | 打开软件、在窗口里打字和点击、移动 / 关闭窗口、整理桌面图标、新建和读写文本文件 |
| 上网 | 用她自己的浏览器（和你的浏览器分开）搜索、打开网页、读内容、截图 |
| 提醒和待办 | “10 分钟后提醒我喝水”“我今天还有什么事” |
| 改设置 | 直接说就行，比如“晚上十一点到早上八点别打扰我” |
| 扩展 | 装插件（MCP / 技能）、换声音、换形象；可以再请别的角色一起住，开群聊 |
| 手机上找她 | 可选：通过 QQ、微信和她聊天（需要另外配置） |

### 实测数据（2026-11-05，20 个常见任务）

- **20 / 20 完成**（第一次跑 19 / 20，那一题当场修好后重跑通过）。
- 开始回应：1.5～6 秒，一般 3 秒左右。
- 做完一件事：简单的十几秒；要操作好几个窗口的，一到两分钟（时间主要花在等模型思考上）。
- 测试全程没动过不该动的东西（主屏 63 个图标 0 移动）。
- 另外测了三项稳定性：你同时在用自己的浏览器、六步跨软件的长任务、做到一半被你打断（她会先回答你，再问要不要接着做），都通过了。

## 做不到 / 还不擅长的

- **不能替你登录、输密码、填验证码、付钱。** 遇到登录或激活窗口，她会停下来告诉你卡在哪，请你自己处理。
- **不会自己画图、做视频。** 要画图需要你另外装 ComfyUI 并接上插件；做视频类的事，她给的是提示词、分镜和脚本。
- **复杂的多步界面操作偏慢**，一件事可能要一两分钟。
- **语音识别对英文软件名容易听错**，可以打字或说中文名。
- **只支持 Windows 10 / 11。**
- 她看屏幕要先得到你同意（见下）；没同意时，她只知道当前是哪个窗口在前面，看不到画面内容。

## 安全：什么时候会问你

- **改动电脑上东西之前会问**：打开软件、打字、移动文件等。你可以选“今天都允许”，省得反复确认。
- **撤不回的每次都问**：删除、覆盖文件、发送消息、关闭程序、付款这类，就算选了“今天都允许”也照样问；你拒绝一次，“今天都允许”就立刻失效。
- **从网上链接装的插件**算“未审核”，它的每个工具每次调用都会问你。
- **任务做完会核对结果**：比如“副屏上有记事本，里面有今天的日期”，核对完卡片上会写“核对通过 3/3”；没通过会如实告诉你。
- **插件拿不到你的密钥**：插件进程拿不到名字像密钥、令牌、Cookie 的环境变量。

## 隐私：什么会离开你的电脑

- **会发出去的**：你和她的对话内容、她的人设和相关记忆，发给你选的模型服务（比如 DeepSeek），用来生成回复。你同意她看屏幕时，截图会发给你设置的视觉模型。
- **只在你电脑上的**：聊天记录、记忆、设置、API Key。
- “导出诊断信息”只包含版本、系统、设置状态，不含聊天内容。

## 要准备什么、要花多少钱

- **必须**：一个 DeepSeek API Key（在 DeepSeek 开放平台注册、充值后创建）。按用量付费，平时聊天花得很少。软件本身免费。
- **可选**：
  - 她的“真声音”要装本地语音（GPT-SoVITS 声音包），需要下载，最好有独立显卡；不装也能用电脑自带的声音。
  - 看屏幕需要一个视觉模型。
  - QQ / 微信需要另外配置。

## 第一次介绍自己时（给小玲）

三四句话讲完：会陪你聊天、会记事（记之前先问）；能在电脑上帮你做事（开软件、打字、整理文件和桌面、上网查），改东西前先问；还能装插件、换声音换样子、请别的角色来住。最后给一个马上能试的例子，比如：“你可以试试对我说：帮我打开记事本，写一句今天的日期。”

## 常见问题

- **她会自己乱动我的电脑吗？** 不会。她只在你让她做事、或你同意她“陪着你看屏幕”时才行动，改东西之前会问。
- **她会一直说话打扰我吗？** 主动聊天默认关着；打开后，她心里有惦记的事才会开口，而且有次数上限，安静时段不说。
- **我说的话会被传到别的角色那里吗？** 不会。角色之间只会互相知道“谁在做什么”（这个功能默认关着），你说的话不会传过去。
- **可以换角色吗？** 可以：换形象、换人设、换声音，或者导入别人分享的人格。
