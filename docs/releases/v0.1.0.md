# AI Pets Hub v0.1.0 Preview

首个 Windows 预览版本 / First Windows preview release

## 下载与运行

- 平台：Windows x64
- 形式：便携版 `.exe`，无需安装
- 首次运行需要在应用内配置兼容的模型服务。请自行准备 API Key，并只在本机应用设置中填写。
- 角色模型、动画和语音素材需自行准备，并确认对应授权。

## 本版内容

- 提供 AI Pets Hub 桌面应用的首个可下载预览版本。
- 包含桌面角色、AI 对话和项目当前的 Agent / MCP 集成基础。
- 项目仍处于早期开源阶段；各子系统成熟度和端到端可用性不同，详见中英文 README 的“项目状态”部分。

## 已知限制

- 应用尚未进行 Windows 代码签名。Windows SmartScreen 可能显示警告；请确认下载来源是本仓库后再决定是否运行。
- 本版是 Windows x64 便携包，不提供安装程序或自动更新器。
- 部分 Agent、桌面操作、语音和第三方集成功能仍在开发与验证，不能视为全部稳定可用。
- 应用图标中的原创角色插画不属于 Apache-2.0 授权范围；允许随本项目应用展示，不授予单独提取、复用或用于其他项目的权利。详见 [`ASSET_LICENSES.md`](../../ASSET_LICENSES.md)。

## Download and run

- Platform: Windows x64
- Format: portable `.exe`; no installation required
- Configure a compatible model provider in the app before using AI chat. Obtain your own API key and enter it only in the local app settings.
- Supply your own character models, animations, and voice assets, and verify their licenses.

## What's included

- The first downloadable preview of the AI Pets Hub desktop app.
- The desktop character experience, AI chat, and the current foundations for Agent and MCP integrations.
- This is an early open-source preview. Subsystems have different levels of maturity and end-to-end availability; see the project status sections in the Chinese and English READMEs.

## Known limitations

- The app is not signed with a Windows code-signing certificate. Windows SmartScreen may show a warning. Verify that the download comes from this repository before deciding whether to run it.
- This is a Windows x64 portable build; no installer or auto-updater is included.
- Some Agent, desktop-action, voice, and third-party integration features are still being developed and validated and should not be considered fully stable.
- The original character illustration in the app icon is excluded from the Apache-2.0 license. It may appear as part of this project, but this does not grant permission to extract or reuse it separately or in other projects. See [`ASSET_LICENSES.md`](../../ASSET_LICENSES.md).
